# Project roadmap

Titanium Orbital Launcher is already a working design prototype. The roadmap below separates verified behavior from ideas that still need engineering and testing.

## Near term

- Add automated tests for settings persistence and catalog classification.
- Add a preview-and-confirm stage before Desktop Organizer moves anything.
- Add remove, reorder, and rename controls for orbit favorites.
- Improve keyboard navigation and screen-reader labels.
- Add radio favorites and recently played stations.
- Show a clearer error when a radio stream is offline or uses an unsupported codec.

## Packaging

- Produce a signed, self-contained Windows release artifact.
- Add release notes and versioned downloads.
- Evaluate MSIX packaging and an optional Start Menu entry.
- Add an in-app version display and update notification.

## Visual system

- Add selectable titanium, black-steel, and cyan-anodized presets.
- Add per-background overlay strength and motion controls.
- Add a reduced-motion preference.
- Refine DPI scaling for small laptops, ultrawide monitors, and multi-monitor setups.

## Radio and media

- Add volume and mute controls.
- Add station metadata and artwork when supplied by the stream.
- Add country, language, genre, and bitrate filters.
- Add a user-managed station URL option.

Roadmap items are proposals, not commitments. Security, data safety, accessibility, and reliable launching take priority over decorative features.
